# WS1 — Backend Enablers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the existing Express API reachable and authenticatable from the bundled Android WebView — add CORS, accept a Bearer token alongside the existing cookie session, issue a longer-lived revocable mobile token, and add the `device_tokens` table — with **zero regression to the web app's cookie login**.

**Architecture:** The web app keeps its httpOnly `sid` cookie. The Android app sends the same session token as `Authorization: Bearer <token>`. A single pure helper `extractToken(req)` resolves the token from header → (GET-only) `?access_token=` query → cookie, so `currentUser()`, every `auth`-guarded route, `/uploads/:file`, and the PDF endpoints all gain token support at once. Session validity moves from a hardcoded 12h to a per-row `expires_at` (web = 12h, mobile = 30d sliding), still fully server-side revocable.

**Tech Stack:** Node ≥ 22.5 (CommonJS), Express 4, Prisma 5 + PostgreSQL, `bcryptjs`, `cookie-parser`, `node --test`. One new runtime dep: `cors`.

**Reference spec:** `docs/superpowers/specs/2026-07-02-android-capacitor-conversion-design.md` (§3, §4.A, §5).

## Global Constraints

- Runtime: **Node ≥ 22.5**, `"type": "commonjs"`. Use `require`, not `import`.
- **Do not change or weaken** existing role gates (`requireRole`), PII masking, or the worker-PII upload prefix gate (`/^(w(doc|photo)|offer)_/` → `DRONA_HR`).
- **Web cookie login must keep working unchanged** — the cookie path is the fallback in `extractToken`, and `SESSION_COOKIE` (server.js:131) is untouched.
- Schema conventions: Int autoincrement PKs, PascalCase models `@@map`'d to snake_case tables, camelCase fields `@map`'d to snake_case columns, `created_at`/`updated_at` as `timestamptz` defaulting to `now()` (no `@updatedAt`). Business dates stay `String 'YYYY-MM-DD'`.
- Raw SQL goes through `db.prepare(sql).get/all/run(...)` (lib/rawdb.js) with `?` placeholders; every call is `await`ed and returns snake_case rows.
- Confirmed params: API domain `https://jmc.dronavaluechain.com`; Android `appId` `com.drona.jmc`; mobile token TTL **30 days sliding**, web **12 hours**.
- Allowed WebView origins (CORS): `https://localhost`, `http://localhost`, `capacitor://localhost`.
- Commit after every task. Branch: `feature/android-capacitor`.

```js
'use strict';
/**
 * Resolve the session token for a request without touching the DB.
 * Order: Authorization: Bearer -> ?access_token= (GET only) -> sid cookie.
 * The GET-only query fallback lets <img>/window.open load auth-gated
 * /uploads and *.pdf from the cross-origin WebView, without exposing a
 * token-in-URL path for mutating requests.
 */
function extractToken(req) {
  const authz = (typeof req.get === 'function' ? req.get('authorization') : req.headers?.authorization) || '';
  const m = /^Bearer\s+(\S+)\s*$/.exec(authz);
  if (m && m[1].trim()) return m[1].trim();

  if (req.method === 'GET') {
    const q = req.query && req.query.access_token;
    if (typeof q === 'string' && q.trim()) return q.trim();
  }

  const c = req.cookies && req.cookies.sid;
  if (typeof c === 'string' && c.trim()) return c.trim();

  return null;
}

module.exports = { extractToken };
```

- [ ] **Step 3: Rewrite `currentUser()`**

Replace the existing `currentUser` (server.js:98-108) with:

```js
async function currentUser(req) {
  const token = extractToken(req);
  if (!token) return null;
  // Validate on expires_at when present (web=12h, mobile=30d); legacy rows
  // created before the migration have NULL expires_at -> fall back to the
  // original 12h created_at rule so existing web sessions stay valid.
  const row = await db.prepare(`SELECT u.*, s.kind AS session_kind, s.expires_at AS session_expires_at
      FROM sessions s JOIN users u ON u.id = s.user_id
     WHERE s.token = ? AND u.active = true
       AND ( (s.expires_at IS NOT NULL AND s.expires_at > now())
          OR (s.expires_at IS NULL AND s.created_at > now() - interval '${SESSION_HOURS} hours') )`)
    .get(token);
  if (!row) return null;
  // Sliding refresh for mobile: keep a 30-day window, but only write when it
  // has drifted below 29 days so we don't UPDATE on every request.
  if (row.session_kind === 'mobile') {
    await db.prepare(`UPDATE sessions SET expires_at = now() + interval '1 hour' * 720
                       WHERE token = ? AND (expires_at IS NULL OR expires_at < now() + interval '1 day' * 29)`)
      .run(token).catch(() => {});
  }
  return row;
}
```

```js
async function pruneSessions() {
```
